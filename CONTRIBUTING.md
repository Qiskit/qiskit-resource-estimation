# Developer guide

- Goal: The purposes and goals of this package are described in [README.md](./README.md).

- Development: This package is developed in collaborative fashion on GitHub.

- Changes: Requests for changes must be submitted as a pull request using the provided template
and require an approval by a maintainer. The submitter must understand their contribution and 
is responsible for maintaining it.

- Releases: There is no fixed release cadence. This package is under active development and not stable.
